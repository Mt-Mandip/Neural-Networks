# Neural-Networks
Neurons and Neural Networks made using only numpy and calculus. Helps understand Tensors, forward-pass, backward-pass and loss analysis. Best i did: Trained on MNIST digit/fashion datasets with decent accuracy.

The code was written before i knew about the importance of comments, so... it has next to no comments, i am sorry (i am not gonna write it). 

# Run for yourself
If you want to run it anyway you may do so anyway you want but, make sure to change the file paths for reading the datasets and saved weights and biases. If you don't want to change the code
make sure the file paths are as follows. You want folder /Neural Networks to contain both /Saved Items(folder) and /______.py(files).

For datasets and saved weights: /Neural Networks /Saved Items / ______.npz (files)
For actual NN code: /Neural Networks / _______.py (files)

Note: you need numpy, Matplotlib, pathlib, etc.
